# Logic & Programming Exercises 🚀

This repository contains programming exercises developed during my Computer Science / Software Engineering studies. 

The projects focus on fundamental logic concepts, control structures, and algorithm design, implemented first in **Portugol Studio** (pseudocode) and then transitioned/translated into **Python**.

### 💻 Technologies & Concepts Covered
* **Portugol Studio:** Basic I/O, conditionals (`se`/`senao`), loops, and pseudocode logic.
