# Portugol Studio - Logic & Algorithms 🧠

This folder contains exercises written in **Portugol Studio**, a pseudocode environment used in college to practice core programming logic and algorithmic thinking.

### 📚 Concepts Covered
* Basic I/O (`escreva`, `leia`)
* Control Structures (`se`, `senao se`, `senao`)
* Arithmetic & Logical Operators (`%`, `e`, `ou`)
* Fundamental algorithms (Odd/Even checks, finding maximum values, positive/negative identification)
