# Python - Logic & Fundamentals 🐍

This folder contains Python exercises developed during my college studies, covering core programming concepts and practical code implementations converted from pseudocode.

### 📚 Concepts Covered
* Data Types & Type Casting (`float()`, `int()`, `str()`)
* Input/Output Operations (`input()`, `print()`, f-strings)
* Control Flow & Conditional Logic (`if`, `elif`, `else`)
* Logical Operators (`and`, `or`, `not`)
* Mathematical Logic (Odd/Even checks, finding maximum values, number classifications)
